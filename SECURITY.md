# Security Policy

Report authentication bypasses, unsafe readiness admission or a path that could
cause a bridge to treat a printer as safe when it is not, privately to
electrohobby3d@gmail.com. Do not publish exploitable details before a fix is
available. This software is not a certified safety system and must never replace
independent emergency stop, guarding or thermal protection.
